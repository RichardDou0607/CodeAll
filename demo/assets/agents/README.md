# CodeAll Agent 图标

这些 PNG 是从本机已安装应用的原始 macOS `.icns` 资源导出的 256px 版本，仅用于本地 CodeAll UI：

- `deepseek.png`：`/Applications/DeepSeek Harness.app/Contents/Resources/icon.icns`
- `claude.png`：`/Applications/Claude.app/Contents/Resources/electron.icns`
- `codex.png`：`/Applications/Codex++.app/Contents/Resources/codex-plus-plus.icns`
- `kimi.png`：`/Applications/Kimi Code.app/Contents/Resources/icon.icns`
- `zcode.png`：`/Applications/ZCode.app/Contents/Resources/icon.icns`

AgentOS、OpenCode 等没有在本机确认到原始安装图标的来源，界面使用 CodeAll 自有图标作为回退。
