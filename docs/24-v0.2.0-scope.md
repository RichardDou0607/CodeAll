## 2. 跨平台的定义

「支持 Windows」= 干净机器安装包安装 → 包内 Node 服务自起 → 会话目录与四态面板按可用性矩阵接线 → 专用测试会话完成 CLI 定向投递与第二轮上下文连续（V01/V02 同口径）→ 双窗口外壳常驻（或明确降级）→ token/Host/只读等安全红线同等生效。不承诺 32 位、Win10 以下、Windows ARM64（[U]，有实机再说）；不承诺 Wayland 穿透置顶全功能；不承诺无发行版源的正常工作。

- 平台抽象层接口先行（PLAT-1）：所有适配器只调 `adapters/platform.mjs`，不得散落 `process.platform` 分支。已定位的平台差异点共四处，全部收进平台层：
  1. `adapters/local-agents.mjs`——进程快照（`ps axo`）、安装路径（`/Applications` 等）、版本读取（PlistBuddy）→ Windows `tasklist`/PowerShell CIM + PE 元数据，Linux 同 ps + `.desktop`；
  2. `adapters/cli-control.mjs`——终端启动链（osascript/Terminal）→ `wt.exe`/`start` → xdg-terminal-exec → gnome-terminal → kitty；无头 spawn 本就跨平台，不动；
  3. `demo/framed.mjs`——插件 socket（`TMPDIR` unix socket，framed.mjs:49）→ Windows 命名管道 `\\.\pipe\agent-pet-*` + TEMP 解析；
  4. `apps/shell/src-tauri/src/lib.rs`——`#[cfg(target_os = "macos")]` 窗口行为块（CanJoinAllSpaces/FullScreenAuxiliary）→ Windows SetWindowPos/WS_EX_TRANSPARENT、X11 EWMH、Wayland 降级。
  另：`session-catalog.mjs` 的 DSH flock addon 回退路径写死 `/Applications/DeepSeek Harness.app`（platform 参数已就绪），收进平台层。
- Tauri 打包目标从 `app`+`dmg` 扩到 NSIS（或 MSI）+ deb + AppImage；包内 Node 的打法沿用 v0.1.0 bundle-service 机制。
- 安全红线不动摇：token 鉴权、Host 校验、观察只读、队列/计划文件 0600 在两个新平台同等实现并进验收断言；Windows 命名管道 ACL 默认仅当前用户可连，在 PLAT-2 实测确认。
- macOS 是回归基线：PLAT-1 完成后 macOS 全套隔离测试必须与改造前逐项一致，不借重构改行为。

## 5. 验证纪律

默认只跑隔离测试（mock CLI、假插件、合成数据），不消耗真实模型额度；真实闭环必须在专用测试会话中由用户明确触发或授权，检查过程中不重启/停止用户正在工作的 Agent。实机验收证据分三级（2026-10-28 PLAT-3 修订）：**E1** 脚本/命令断言全绿；**E2** 本机可控 VM 截图自动化（vmlab / ssh+xwd，可承担 W05/W06 的窗口行为与安装包验收取证）；**E3** 物理机人工。W06 正式收口取 E3 或用户明示豁免以 E2 代；原「VM 只能做功能冒烟」口径按此分级改写。降级声明先于发布落位（README + 产品界面），宣传不跑在实现前面。
