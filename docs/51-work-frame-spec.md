## 1. 定位与设计原则

**一句话**：工作框是一个**常驻、贴边、高度自适应的小卡片**；首行用 40 px 回答「现在在干什么、干了多久、有没有卡在等我」，其下每个会话一行 28 px 回答「哪几个会话、各自什么状态」。宠物只是它旁边一个**默认关闭**的可选图层。

### 1.1 五条设计原则（冲突时的裁决顺序）

| # | 原则 | 含义 | 优先级 |
|---|---|---|---|
| P1 | **状态先于角色** | 任何美术/动画都不得挤压首行与会话行的信息可读性 | 最高 |
| P2 | **首行四项 + 会话行两项常驻** | 首行 40 px 内必须读出：①聚合状态 ②当前动作 ③计时 ④未决计数；每会话行 28 px 内必须读出：①会话标识 ②该会话状态（+计时或最近动作） | 高于 P4/P5 |
| P3 | **零推断** | 一切时间/进度取 Hub 的 `snapshot`（契约 §8.2）；客户端不读本地时钟、不估算 ETA | 高于 P4/P5 |
| P4 | **降级显式** | 离线/降级/粗略模式/能力缺失一律有角标或明确隐藏，**不得假装正常**（契约 §8.3） | 高于 P5 |
| P5 | **打扰可退、宠物可关** | 声音/闪烁/置顶可单独关闭；**宠物图层默认关闭**，关闭后信息一项不少 | 最低 |

### 1.2 信息分级

| 级别 | 内容 | 出现位置 |
|---|---|---|
| **L0 常驻** | 首行四项（聚合状态 / 当前动作 / 计时 / 未决计数）；每会话行的会话标识 + 该会话状态 | 所有形态 |
| **L1 一眼可见** | 后端色条、离线/降级/粗略角标、瞬态错误一闪、`+N` 折叠标记 | 首行右侧、会话行左端 |
| **L2 展开可见** | 完整会话列表、被清理的未决项、计数器详情 | 「全部会话」页 / 待办页 / 诊断页 |
| **L3 装饰（默认关闭）** | 宠物动画、特效 | 宠物层（独立图层） |

## 2. 形态

### 2.1 悬浮卡片（**默认形态**）

```
┌──────────────────────────────────────────────┐ 0
│▌ ●  工作中 · npm test      02:14   ⏳1   ⌃   │ 40  ← 首行（固定 40 px）
├──────────────────────────────────────────────┤
│ ▌D ● 桌宠（agent桌宠）     工作中   02:14 ⏳1 │ 28  ← 会话行
│ ▌C ● api-fix/api-fix       思考中   00:42    │ 28
│ ▌D ○ docs                  空闲       —      │ 28
│ ▌D ◐ 实验分支              思考中   01:07    │ 28
├──────────────────────────────────────────────┤
│ +1 个会话 · 待办 1 · 已清理 0                 │ 22  ← 折叠/状态脚注（有内容才出现）
└──────────────────────────────────────────────┘ 40+28×N(+22)
```

**首行（40 px）分区**

| 区 | x 区间（px，卡片宽 360） | 内容 | 数据来源 | 规格 |
|---|---|---|---|---|
| A 状态色条 | 0–4 | 整高 4 px = 聚合状态色 | `snapshot.agg` | 瞬态错误时闪黄 2 s（§3.1） |
| B 状态灯 | 8–20 | 12×12 圆点（形状+颜色双编码） | `snapshot.agg` | waiting 时 1 Hz 脉动（Reduce Motion 下静止） |
| C 状态+动作 | 24–248 | `聚合状态 · 当前动作` | `agg` + `now.lastTool` | 12 px；**动作保底 8 个全角字符** |
| D 计时 | 252–292 | `mm:ss` / `h:mm:ss` | `now.elapsedMs` | 12 px 等宽数字；`now=null` → `—` |
| E 未决计数 | 296–320 | `⏳N`（N>0 才出现） | 未决登记（§3.3） | 点击 → 待办页 |
| F 收起/展开 | 328–344 | `⌃` / `⌄` | — | 收起 → 窄条形态 |
| G 宠物挂点 | 348–356 | 宠物开启时的 8 px 连接点（关闭时不显示） | — | 见 §6 |

宽度预算（360 px）：4 + 4 + 12 + 4 + 224 + 4 + 40 + 4 + 24 + 8 + 16 + 4 + 8 + 4 = 360 ✓
高度：**40 px**（上下 padding 8 px，内容行高 24 px）。

**会话行（28 px）分区**

| 区 | x 区间（px） | 内容 | 数据来源 | 规格 |
|---|---|---|---|---|
| a 后端色条 | 0–3 | 3 px 竖条，按 `source` 着色 | `session.source` | D=蓝 / C=橙 / X=紫 / A=青（**[假设]**，主题包统一） |
| b 状态灯 | 10–20 | 10×10 圆点（形状+颜色双编码） | `session.state` | waiting 脉动；error 常亮红 |
| c 会话标识 | 26–170 | 工作目录末段 / 会话名（`title` > `workspace` 末段 > `sessionId` 后 6 位） | `sessions[].title`/`workspace`（契约 v1.2 已提供） | 11 px，超宽省略号，保底 **6 个全角字符** |
| d 计时或最近动作 | 174–300 | 该会话 `elapsedMs`；无则 `lastTool`；都无则 `—` | `sessions[].elapsedMs`/`lastTool`（契约 v1.2 已提供） | 11 px 等宽数字 / 11 px 文本 |
| e 该会话未决标记 | 304–320 | `⏳`（该会话有未决时） | 未决登记（§3.3） | 12 px |
| f 跳转热区 | 324–352 | 点击 → 跳到该会话后端窗口 | — | hover 时显示 ↗ |

会话行高度 **28 px**（上下 padding 6 px，行高 16 px）。

**窗口高度公式（与契约 §8.1 逐字一致）**：`height = 40 + 28 × min(N, 5) + (N > 5 ? 22 : 0)`（N = 会话数）；**仅首行（窄条）= 40 px**；N=1 时 68 px（22 px 脚注只在折叠或有待办/已清理内容时出现）。

**Retina / 缩放规格**
- 布局单位一律 **CSS px**，不随缩放变化；图形资源按 **@2x/@3x** 提供（或纯矢量）。
- 文字使用系统字体（SF Pro / 系统 UI 字体），启用系统字重与字距；**不使用位图文字**。
- 1× 屏：首行 12 px / 行高 16 px；会话行 11 px / 行高 14 px。2×/3× 屏：CSS px 不变，物理像素翻倍，描边保持 1 CSS px（物理 2–3 px）以免发虚。
- 跟随系统「更大文本」：12 → 14 px 时首行 40 → 48 px、会话行 28 → 32 px（高度公式同步按新常量计算）。
- 半透明材质（vibrancy）在 Retina 下需实测文字对比度（§7 WF-26）。

### 2.2 行数上限与折叠（**已确认，与契约 §8.1 一致**）

| 常量 | 取值（默认口径） | 说明 |
|---|---|---|
| `MAX_SESSION_ROWS` | **5** | 卡片内最多显示 5 个会话行；第 6 个起折叠为 `+N`（对应 Lead 给出的验收项「第 6 个会话折叠为 +1」） |
| 最大高度 | `40 + 28×5 = 180 px`（+22 脚注 = 202 px） | 超出不再增长 |
| `MIN_ROWS` | 1 | 无会话时只显示首行（40 px） |

> **口径已确认（2026-10-05，Lead）**：`MAX_SESSION_ROWS = 5` **只数会话行、不含首行**；第 6 个会话起折叠为 `+N`，窗口高度 = `40 + 28×min(N,5) + (N>5 ? 22 : 0)`。**与契约 §8.1 一致**；此前「上限 5 含首行」的口径已废弃，`MAX_SESSION_ROWS` 仍作为唯一配置常量（改它即可整体改口径）。
- 折叠行脚注文案：`+N 个会话`（可点击 → 「全部会话」页）；脚注同时承载「待办 N · 已清理 N」入口（有内容才显示整条脚注）。
- **全文会话列表**页：无高度限制的普通窗口，含排序、筛选（仅活跃 / 仅等待）、逐行跳转。

### 2.3 窄条 320×40（可选，仅首行）

```
┌──────────────────────────────────────────────────────────────────────┐
│▌ ●  工作中 · npm test                    02:14   ⏳1   ▮2   ⌄       │
└──────────────────────────────────────────────────────────────────────┘
```

- 就是卡片的**首行**（同分区、同字号、同数据源），宽 320 px：C 区收窄到 186 px（动作仍保底 8 全角字符，校验见 §2.1 的算法）。
- 会话信息压缩为右侧 `▮2` 徽标（2 = 会话数，点击展开卡片）。
- 用途：用户主动收起的常驻窄条；也是**全屏应用时自动收起的形态**（§4.1）。

### 2.4 宠物形态（可选）

```
        ╭────────╮
        │  ● ⌃   │   ← 96×96 宠物（用户显式开启宠物图层时）
        │  (pet) │
        ╰────────╯
   ▌ 工作中 · npm test   02:14  ⏳1    ← 脚下 36 px 迷你条（= 首行的压缩版，四项常驻）
```

- 仅当用户开启宠物图层并选择「宠物形态」时出现；四项 L0 信息在脚下迷你条中保持可读。
- 迷你条宽 200–260 px 自适应，动作保底 8 全角字符。

### 2.5 形态切换（不重连 Hub）

| 触发 | 行为 |
|---|---|
| 点击 F 区 | 卡片 ⇄ 窄条（首行） |
| 点击折叠行/徽标 | 展开卡片 / 「全部会话」页 |
| `⌥⌘F` | 卡片 → 窄条 → 宠物形态 → 卡片（循环；宠物形态在宠物图层关闭时自动跳过） |
| 右键菜单 | 直接选择：卡片（默认）/ 窄条 / 宠物形态 |
| 全屏应用检测 | 自动收为窄条（320×40），退出后 1 s 内恢复原形态与位置 |

> **硬约束**：形态切换只切渲染，**不重连 Hub、不重新订阅**；socket 连接数与快照 `ts` 连续性可验证（§7 WF-15）。

## 3. 信息架构、配色与计时

### 3.1 状态配色与文案表

| 状态 | 色（浅色 / 深色） | 形状编码 | 文案（zh-CN / en） | 首行动作行 | 会话行“计时或最近动作” | 停留 |
|---|---|---|---|---|---|---|
| `idle` | #64748B / #94A3B8 | 空心圆 ○ | 空闲 / Idle | 最近动作或 `—` | 时长或 `—` | — |
| `thinking` | #2563EB / #60A5FA | 半环 ◐ | 思考中 / Thinking | 「在想…」或摘要（≤12 字） | 时长 | — |
| `working` | #059669 / #34D399 | 实心圆 ● | 工作中 / Working | `now.lastTool` | 时长 | — |
| `waiting` | #D97706 / #FBBF24 | 实心圆 + 外环 ◎ | 等你确认 / Waiting | `审批：{{kind}}` | 「等你确认」 | 不自动退出 |
| **`transient-error`** | **#CA8A04 / #FDE047** | 三角 △ | 重试中 / Retrying | 失败的 `toolName` | 最近动作 | **2 s**（timeout 1.5 s） |
| **`error`（持久）** | **#DC2626 / #F87171** | 方块 ■ | 出错 / Error | 错误结论首行（≤12 字） | 「出错」 | 常驻至成功事件/清理 |
| `done` | #0D9488 / #2DD4BF | 对勾 ✓ | 完成 / Done | 摘要（≤12 字） | 时长 | 2 s |
| 离线 / 降级 / 粗略 | #6B7280 + 斜纹 | 斜纹 + ⚠ | 离线 / Degraded | `—` | 时长冻结 + 「已冻结」 | 持续到恢复 |

规则：
1. **对比度**：文字与底色 ≥ **4.5:1**（WCAG AA）；半透明材质下需在同一背景实测（§7 WF-20/WF-26）。颜色为 **[假设]**，M1 原型上做 5 人可用性测试后定稿。
2. **不只靠颜色**：每状态配形状编码 + 文本（色盲友好）。
3. **瞬态 vs 持久（契约 §4.7）**：`step.end(error)`/`tool.result(error)` = **黄色一闪 2 s** 后回上一稳定状态；`turn.end(error)`/`session.end(error)`/`error.raised(fatal=true)` = **红色常驻**；同一会话 60 s 内连续 3 次瞬态 → 升级为持久红（`escalatedErrors`）。
4. **不做背景色块**：错误/警告背景色只作最后手段 [参考 VS Code 指南]；仅在「持久错误 + 未决 >0」同时成立时给整框 1 px 红描边。

### 3.2 计时规则（严格零推断）

| # | 规则 | 依据 |
|---|---|---|
| T1 | 首行计时**只**取 `snapshot.now.elapsedMs`；`now=null` 显示 `—`（**不是 0**） | 契约 §8.2 |
| T2 | 会话行计时取 `sessions[].elapsedMs`（契约 v1.2 已提供）；缺失时回退 `snapshot.ts − session.since`（同帧两字段相减，仍**不读本地时钟**），并按 §3.4 的 `observes` 规则决定是否显示 | 契约 §5.3 |
| T3 | source 离线时该 source 的所有计时**冻结**并标「已冻结」，不继续走字 | 契约 §4.4/§8.3 |
| T4 | **禁止**：本地 `Date.now()`/`performance.now()` 计算时长、ETA、百分比进度（除非 `now.stepIndex` 与总数都在快照中） | 契约 §8.2 |
| T5 | 计时文本每秒更新一次，更新时刻对齐快照到达（不按动画帧刷新） | docs/10 §7 空闲 CPU ≤1% |
| T6 | 格式：`<1 h` → `mm:ss`；`≥1 h` → `h:mm:ss`；`≥24 h` → `1d 3h` | 本规格 |

### 3.3 未决计数（PendingQueue）

- 首行 `⏳N`：N = 全部未决（审批 + 提问）；**N=0 时整块隐藏**。会话行 `⏳`：该会话有未决时显示。
- `waiting` 时 1 Hz 脉动；点击 → 待办页（`⌥⌘K`）；右键 → 「跳到等待中的窗口」（`⌥⌘J`）。
- **Phase 1 只读**：卡片、待办页均**无**允许/拒绝按钮（契约 §5.4）。
- **被清理的未决项**（契约 §4.5 + `snapshot.clearedPending`）：脚注显示「已清理 N」，待办页列出 `requestId` / 时刻 / 原因，**不得静默消失**（docs/50 §1.3 的留痕承诺在此落地）。
- **计数来源（契约 v1.2 已提供）**：首行 `⏳N` = Σ `sessions[].pending`（Hub 为每个会话提供未决计数，缺省视为 0）；`clearedPending[]` 提供被清理项历史。若某适配器不上报 `approval.*`/`user.*`（§3.4），该会话 `pending` 视为 0 并隐藏行内 `⏳`。

### 3.4 能力协商导致的指标隐藏（契约 §5.2.1 `observes`）

| `observes` 缺失的族 | 首行 | 会话行 | 不得做的事 |
|---|---|---|---|
| `step.*` | 隐藏步骤进度（若有进度条） | — | 不显示 0 / 空白 / 灰条 |
| `tool.*` | 动作行退化为状态文本 | 「计时或最近动作」列回退为计时 | 不显示假工具名 |
| `approval.*`/`user.*` | 隐藏 `⏳N` | 隐藏行内 `⏳` | 不显示 `⏳0` |
| `turn.*` | 计时区显示 `—` + tooltip「该后端不上报轮次」 | 同上 | 不用本地时钟补计时 |

- 每个被隐藏的指标都要在「全部会话」页或卡片 tooltip 里可查到原因（例如「DSH：不支持步骤进度」），避免用户误判为故障。

### 3.5 离线 / 降级 / 粗略模式（契约 §8.3）

| 情形 | 角标 | 首行文本 | 计时 | 会话行 |
|---|---|---|---|---|
| `offlineSources` 非空 | 灰底斜纹 + ⚠ + 后端名（≤2 个 + N） | 「离线」 | 冻结 + 「已冻结」 | 该 source 的行整行灰化 + 斜纹 |
| `degradedSources` 非空（契约 §5.3 字段；offline=完全无事件，degraded=有事件但有缺口） | 琥珀描边 + ⚡ | 「降级」 | 照常（Hub 仍提供时） | 行尾 ⚡ |
| 粗略模式（docs/10 §8 进程级兜底） | 虚线框 + ◌ | 「粗略」 | `—` | 只显示两态（在跑/空闲），隐藏工具与步骤 |

## 4. 交互

### 4.1 拖拽、吸边、多屏、全屏、刘海避让

| 交互 | 规则 | 边界 |
|---|---|---|
| 拖拽 | 卡片整体可拖（会话行区域也可拖；行内热区除外）；跟手 ≤16 ms；拖动时 80% 透明 | 拖动中不触发点击展开/跳转 |
| 吸边 | 松手距屏幕边缘 <80 px → 吸附左/右/下（**顶部默认不吸附**）；贴边 4 px | 吸附误差 ≤4 px |
| 高度变化 | 会话数变化时卡片**向下增长**；贴底边时向上增长（保持贴边侧不动，避免跳动） | 增长不得移出屏幕 |
| 位置记忆 | `config.json`：`{mode, screenId, edge, offsetX, offsetY, locked, petLayer:{enabled, x, y}}` | 重启恢复；屏幕不存在 → 回主屏 |
| 锁定位置 | 右键「锁定位置」→ 不可拖动（防误拖）；锁定态显示 4 px 虚线边 | 菜单可解锁 |
| 多屏 | 默认跟随鼠标所在屏；可锁定屏；拔插/分辨率变化 500 ms 内重定位并完整可见 | 不停留在已断开屏幕坐标 |
| 刘海/菜单栏避让 | 顶部吸附禁用；自动布局避开菜单栏与刘海安全区（**[未验证]**：`NSScreen` 安全区 API 需在带刘海机型实测） | 不覆盖菜单栏图标区 |
| 全屏应用 | 检测到前台全屏 → 自动收为**窄条 320×40（仅首行）**、静音、帧率降半；退出全屏 1 s 内恢复原形态/位置/高度（**Lead 已裁决以本文为准**，docs/50 §2.10 已同步） | 该自动行为可关闭；**收起后四项 L0 仍可读**（不牺牲信息） |

### 4.2 展开 / 收起 / 跳转

- 点击 F 区：卡片 ⇄ 窄条。点击折叠脚注或 `+N`：展开卡片 / 打开「全部会话」页。
- 点击会话行 f 区（↗）：跳到该会话对应后端窗口/终端（Phase 1 只跳转，不写回）。
- 首行 C 区点击：无操作（避免误触）；E 区 → 待办页。

### 4.3 点击穿透

- `⌥⌘P` 或右键切换；开启后不接收鼠标事件（`setIgnoreMouseEvents(true, {forward:true})` 语义）。
- 退出路径：菜单栏图标常驻 + `⌥⌘P` 再按一次 + 菜单栏显示「穿透中」角标；穿透态框体加 30% 透明。
- 穿透仅关闭鼠标事件，四项信息照常刷新。

### 4.4 右键菜单（15 项，**Lead 已裁决以本文为准**）

## 5. 多会话与多后端（会话行规则）

### 5.1 会话行内容与排序

| 规则 | 取值 |
|---|---|
| 行内容 | 后端色条 + 状态灯 + 会话标识（`title` > workspace 末段 > `sessionId` 后 6 位）+ （计时 或 最近动作）+ 该会话 `⏳` + ↗ 跳转 |
| 排序 | `waiting > error > working > thinking > done > idle`；同级按最近事件倒序 |
| 置顶 | 新出现 `waiting` 的会话行临时高亮 3 s（不改变排序稳定性） |
| 色条 | 按 `source` 着色（多后端一眼区分） |
| 悬停 | tooltip 显示完整 workspace 路径 + 会话 ID + 已运行时长（脱敏：路径只到末两段） |

### 5.2 折叠与上限

| 会话数 | 卡片显示 | 折叠脚注 |
|---|---|---|
| 0 | 仅首行（40 px） | 不显示 |
| 1–5（**已确认口径**） | 全部会话行 | 无折叠，仅显示「待办/已清理」脚注（若有内容） |
| ≥6 | 前 5 行 | `+N 个会话`（N = 总行数 − 5）→ 点击进「全部会话」页 |
| 无高度上限页 | 「全部会话」页列出全部（可筛选/排序） | — |

> 口径已由 Lead 确认（2026-10-05）：`MAX_SESSION_ROWS = 5`（会话行，不含首行）——**与契约 §8.1 一致**。若未来要改为 4，只需改这一个常量并同步本表阈值。

### 5.3 多后端与聚合

- 聚合状态**只认** `snapshot.agg`（契约 §4.3），工作框不重算。
- `turn.end(aborted)`/`session.end(aborted)` 的会话级例外（契约 §4.2）：某会话中断只是该行回 `idle`，**不打断**其他会话的 `waiting`（§7 WF-22）。
- 首行汇总口径：`⏳N` 统计**全部**未决；动作行取「最近发生状态变化的会话」的动作（Hub `now` 已给），不自行挑选。

## 6. 宠物层（**默认关闭**）

### 6.1 定位

- **默认极简**：安装后只有卡片；宠物图层是用户显式开启的**独立可拖拽图层**（独立窗口，与卡片分离，可放到卡片左侧/上方/任意位置）。
- 开启入口（三处，任一）：① 首次启动引导第 1 步「想要一个陪伴角色吗？」② 右键菜单「显示宠物图层」③ 设置 → 外观 → 宠物图层（含角色/皮肤选择）④ 快捷键 `⌥⌘L`。
- 开启后：默认出现在卡片左侧 8 px 处、与卡片首行底部对齐；可自由拖动；位置独立记忆。
- 关闭后：图层隐藏，**不改变任何信息布局**（§7 WF-17）。

### 6.2 职责边界（硬约束）

| 信息 | 工作框 | 宠物层 |
|---|---|---|
| 首行四项 + 会话行两项 | **必须承载** | 可「顺便」表达，**不得是唯一载体** |
| 离线/降级/粗略角标 | **必须承载** | 可加情绪表现（打伞/举牌） |
| 情绪、陪伴、轻量进度暗示 | 可选（首行小图标） | **主场** |
| 气泡文案 | 可选（紧凑提示） | 主场（开启时） |

> 评审判据：**把宠物层整体关闭后，L0/L1 信息一项都不能少**。

### 6.3 极简模式视觉方案

```
┌──────────────────────────────────────────────┐
│▌ ●  工作中 · npm test      02:14   ⏳1   ⌃   │   ← 与默认完全一致
├──────────────────────────────────────────────┤
│ ▌D ● 桌宠（agent桌宠）     工作中   02:14 ⏳1 │
│ ▌C ● api-fix/api-fix       思考中   00:42    │
└──────────────────────────────────────────────┘
```

- 极简 = **默认形态本身**（无宠物图层）；视觉上更「工具化」：纯矢量图标 + 系统字体 + 半透明材质，无动画（仅状态切换时的 120 ms 淡入）。
- 收益（**[假设]**，待 docs/30 实测）：空闲 CPU ≤0.3%、无 GPU 动画、内存占用低于含宠物图层 ≥20 MB。
- 宠物可随时开启/关闭，**不触发 Hub 重连、不改变卡片尺寸**（卡片宽度固定 360 px，宠物在独立图层）。

### 附：本轮（v0.2）变更记录

1. **默认形态改为悬浮卡片**：首行 40 px（状态灯 + 聚合状态 + 当前动作 + 计时 + 未决角标）+ 每会话行 28 px（会话标识 + 状态 + 计时/最近动作）；高度 = `40 + 28×可见会话数`（+22 脚注）。
2. **行数上限已确认**：`MAX_SESSION_ROWS = 5`（**只数会话行**，不含首行），第 6 个会话折叠为 `+N`；窗口高度 = `40 + 28×min(N,5) + (N>5 ? 22 : 0)`，**与契约 §8.1 逐字一致**。
3. **窄条 320×40 降为可选形态**（= 仅首行），并成为全屏应用时的自动收起形态（信息不缺失）。
4. **宠物默认关闭**：改为卡片旁**独立可拖拽图层**，开启入口 4 处，关闭不影响任何信息；极简模式 = 默认形态。
5. **验收清单扩到 27 条**，新增：3 会话高度 124 px、第 6 会话折叠 `+1`、高度序列、贴边向上增长、Retina 清晰度、关闭宠物信息不缺失、首行四项可读、更大文本适配。
6. **契约表述修正**：不再照抄「窄条 36–48 px」，改为「首行 40 px（可配 36–48）+ 每会话行 28 px」；并新增 §9-G7（会话行所需字段）与 §9-G8（§8.4 表述）两条建议。
